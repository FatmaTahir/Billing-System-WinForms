# Windows Forms Billing System
---
A desktop billing system developed in C# Windows Forms for Software Construction and Development Homework 05. The application allows users to add products, calculate totals, apply discounts, remove items, clear the bill, and view activity logs using the Publisher-Subscriber pattern with C# Events and Delegates
 ---

# ✨ Main features
- Add products with name, quantity, and price
- Validate product information using a custom delegate
- Display products in a DataGridView
- Calculate subtotal and discounted total
- Apply discount using Func<double, double>
- Display bill generation date and time
- Remove selected products
- Clear the complete bill
- Activity logging using Action<string>
- Publisher-Subscriber pattern using C# events
- OnItemAdded event
- OnBillCalculated event
- OnBillCleared event
- Multicast event subscribers
- Lambda/anonymous event subscription
- Separate BillingLogger subscriber class
